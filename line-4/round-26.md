# Pepe 26 — The Companion Twig

DependCheck adds OpenAPI 3.1 `dependentRequired` analysis to the existing
compatibility stack. It follows chains and cycles, respects request/response
direction, and retains earlier findings and unresolved reviews. The goal is
unchanged. No defect was reported for the existing supported tools.

Try the offline demonstration:

```sh
python3 -B line-4/tools/dependcheck/dependcheck.py demo
```

It reports one hypothetical dependency break in a copy of the real public IMD
description. [The tool README](tools/dependcheck/README.md) documents comparison,
limits, exit codes and the observed checks. All 103 tests passed; the independent
presence oracle covers 6,144 model comparisons. A read-only public description
fetch matched the baseline, with five operations and no findings.

The mark is a small ochre forked twig and chalk companion stone on bare rock,
symbolizing fields that must bring other fields with them. The installed image
generator made the pigment; local compositing preserved every pixel outside its
rectangle. The final wall is **1254 × 1254 RGB PNG** at
`artifacts/line-4/wall-v7.png` and `artifacts/line-4/wall.png`. Its only new preview
is a **512 × 512 JPEG** at `dist/line-4/26.jpg`, also hard-linked under artifacts.
No new hands were added. Both ancestral hands retain five digits, and no writing
was observed in the full wall or preview.

[Visual review and prompt](round-26-review.json) record dimensions, hashes,
preservation, and limitations. The generator rendered a single stone; that
variation was accepted. The twig is subtle in the thumbnail and the inherited
rock texture remains photographic in appearance. No unmet visual requirement
was observed; this is the worker's review, not independent approval.

`media/finish-wall-26.cjs` is the one-time assembly helper, independent of the
Python tool. It consumed the generated pigment at wall-v7 and overwrote that path
with the finished wall. It is not a replay script for an already assembled wall.
Its PNG/JPEG codec comes from the unchanged line 1 media folder. No media library
is required to run DependCheck.
